# pi-search-control

A personal search control plane for Pi. See `CONTEXT.md` for the project's language and `docs/requirements.md` for the confirmed V1 scope.

This is an attributed MIT-licensed fork of [`pi-web-lite`](https://github.com/smithyyang/pi-web-lite); see `docs/adr/0001-fork-pi-web-lite-for-provider-adapters.md`. Upstream is kept as the `upstream` git remote.

## Agent skills

### Issue tracker

Issues and specs live as markdown files under `.scratch/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical triage roles, each label string equal to its role name. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` plus `docs/adr/` at the repo root. See `docs/agents/domain.md`.
